  • Hyperbolic probing of LLM reasoning

    0.967 Spearman ρ, hyperbolic probe
    Interpretability · ICML 2026 workshop

    A Poincaré ball probe over the hidden states of DeepSeek R1 Distill Qwen 7B recovers reasoning depth at 0.967. The matched Euclidean probe collapses to 0.488. I implemented the probe and ran the curvature and dimension ablations. The gap is the result.

    PyTorch · Transformers · hyperbolic geometry

Software systems

a forward pass, one pixel at a time

Three systems I built end to end and measured properly. Every number below comes from a load test or an experiment.

  • Real time social feed

    3,500 → 25k connections, before and after tuning
    Distributed systems · 2026

    Posts, threaded replies, reactions, live presence and typing indicators. Cross instance fan out over WebSockets backed by Redis Pub/Sub, and opaque cursors after offset pagination produced duplicates under concurrent writes. The first k6 run capped near 3,500 sockets per instance on file descriptor limits. After kernel tuning and a horizontally scaled socket tier behind sticky sessions: 25,000 concurrent connections at p50 18 ms, p95 42 ms, p99 85 ms.

    TypeScript · Node.js · Redis · PostgreSQL · React · Docker · k6

  • Experimentation platform

    5% → 14% false positives from daily peeking
    Applied statistics · 2026

    Deterministic assignment by hashing user ID with a per experiment salt, so no central assignment service is needed. A client SDK evaluates flags in process with stale while revalidate refresh. Exposures flow through Kafka into t tests and guardrails. A Monte Carlo study over 100,000 synthetic users and 10,000 runs showed naive daily peeking inflates false positives from 5% to about 14%, so I added a sequential testing correction. Chi square sample ratio mismatch alerts at p below 0.01, and there is a one click kill switch.

    Python · FastAPI · Kafka · PostgreSQL · SciPy · React

  • AI code review agent

    −68% cost at equal quality
    LLM systems · 2026

    Reviews pull requests for correctness, maintainability, style, documentation and test coverage, but most of the work was the harness: a 1,200 example golden set with edge and adversarial cases, deterministic checks plus an LLM judge calibrated to human labels, and a CI regression gate that fails the build when scores drop. Routing style only reviews to a smaller model cut cost 68% at equal quality, near $1.80 per 1,000 requests. PII redaction before any external call, confidence based escalation to humans, bias audits across four languages. Turnaround down 52%.

    Python · LangChain · GitHub Actions · Prometheus · Grafana · PyTest
